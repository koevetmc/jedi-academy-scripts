# Jedi Academy Scripts

A collection of scripts for Star Wars Jedi Knight: Jedi Academy
(JA / JKA), targeting the base game and OpenJK-based engines.

## Contents

- `scripts/` — config (`.cfg`) scripts and other utilities

## Usage

### Config scripts (`.cfg`)

1. Copy the `.cfg` file into your `GameData/Base` folder
   (for OpenJK on Windows: `Documents/My Games/OpenJK/base`).
2. Launch the game, open the console with ``Shift + ` ``, and run:

   ```
   exec <scriptname>
   ```
